    How to read the map

    Every star is a film. Films sit close together when the same people rated them the same way, not because someone tagged them with the same genre.

    The positions come from a matrix factorization model trained on MovieLens ratings. It learns a …-number vector for every film; UMAP squashes those vectors into the three dimensions you can fly through. A few films that are close in the full space look apart here, so the Closest in taste list in each card uses all … dimensions.

    Bigger, brighter stars have more ratings. Colour is each film's most distinctive genre.

    Data: MovieLens, GroupLens Research. Harper & Konstan, ACM TiiS 2015.
